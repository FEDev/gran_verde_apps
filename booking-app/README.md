# Booking App

A TypeScript-based booking application built with Prisma ORM.

## Configuration

See `tisconfig.json` for application configuration.

## Tech Stack

- **Runtime**: Node.js
- **Language**: TypeScript 12.1.0
- **ORM**: Prisma 5.7.0
- **Environment**: Development

## Setup

```bash
npm install
```

## Project Structure

- `/booking-app` - Main application directory
